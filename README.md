
# GRIDPULSE – Smart Electricity Demand Forecasting

### Predict Smartly, Prepare Early!

## About the Project

GRIDPULSE is a smart electricity demand forecasting system that uses Machine Learning and weather information to predict electricity demand for the next seven days.

It also provides a What-If Simulator that helps users understand how changes in temperature may affect electricity demand.

## Problem Statement

Electricity demand changes with weather conditions. Sudden temperature increases and changing weather patterns can make demand difficult to predict, creating challenges in electricity generation and resource planning.

## Proposed Solution

GRIDPULSE combines historical weather information with Machine Learning to forecast electricity demand and provide actionable insights through an interactive dashboard.

## Key Features

- Seven-day electricity demand forecasting.
- Interactive dashboard with daily predictions.
- What-If temperature simulator.
- Dynamic prediction graph.
- Actionable advice for demand preparedness.
- Location selection interface.

## Technologies Used

- Python
- Flask
- Machine Learning – Random Forest Regressor
- HTML
- CSS
- JavaScript
- Chart.js
- Pandas and Scikit-learn

## Dataset

The prototype uses 25 years of historical weather data (2001–2025) and realistic synthetic electricity-demand profiles for demonstration.

The electricity-demand values are synthetic and are not actual HESCOM measurements.

## How to Run the Project

1. Clone the repository:

   git clone https://github.com/K-vidya805/GRIDPULSE.git

2. Open the project folder:

   cd GRIDPULSE

3. Install the required packages:

   pip install -r requirements.txt

4. Run the Flask server:

   python server.py

5. Open the local URL displayed in the terminal in your browser.
